# PersonaLens

합성 페르소나로 설문을 시뮬레이션하는 연구용 프로토타입입니다. 1차 사용자는 정책·여론 연구자입니다.

`legacy/`의 바닐라 JS 프로토타입(v4)을 기능·화면·문구·동작 그대로 React + Vite로 옮긴 버전입니다.

## 문서

- [개발 문서](docs/development.md) — 폴더 구조, 원본과 달라진 점, 기준값 바꾸는 곳, 테스트 구성
- [변경 기록](docs/CHANGELOG.md) — juno·jiyeon 브랜치에서 바뀐 내용
- [마이그레이션 노트](docs/MIGRATION_NOTES.md) — 전환 작업 진행 기록

## 실행 방법

```
npm install
npm run dev      # 개발 서버
npm run build    # 프로덕션 빌드
npm run preview  # 빌드 결과 미리 보기
npm test         # Vitest (원본 대비 회귀 테스트 포함)
```

데이터는 브라우저 `localStorage`(키 `personascope-proto-v4`)에 저장됩니다. 처음 실행하면 예시 프로젝트가 자동으로 만들어지고, 프로젝트 목록 화면 아래의 "예시 데이터 다시 만들기"로 초기화할 수 있습니다.

원본 프로토타입은 `legacy/index.html`을 브라우저로 직접 열면 됩니다(서버 불필요).

## 시연용 한계

실제 서비스가 아닌 시연용 프로토타입이라 다음과 같은 한계가 있습니다(`legacy/REVISION_NOTES.md`의 "시연용 한계" 참고).

- **응답은 시연 생성기가 만든 가짜 데이터**입니다. 문항마다 속성 몇 개에 따라 확률이 조금씩 달라질 뿐이라 차이 크기 자체에는 의미가 없습니다.
- **인원 추정치**는 조건 항목끼리 독립이라고 가정한 근사치입니다. 실제 원자료를 조회하지 않습니다.
- **서술형 조건**(취미, 페르소나 서술 등)은 시연 데이터에 서술 내용이 없어 집단 구성에 적용되지 않습니다.
- **직업 대분류**는 매핑 데이터가 없어 분석용 속성에서 제외했습니다.
- **인터뷰 답변은 템플릿**입니다. AI API와 연결되어 있지 않습니다.
- **다크 모드는 지원하지 않습니다.**
